# Gamepad Compatibility

| Controller | Connection | Buttons | Analog Sticks |
|------------|------------|---------|---------------|
| Sony PlayStation Classic Controller | USB | OK | Not available |
| Sony DualShock 3 (genuine) | USB | OK | OK |
| Sony DualShock 3 (genuine) | Bluetooth | OK | OK |
| Sony DualShock 4 | Bluetooth | OK | OK |
| Sony DualShock 3 (SHANWAN clone) | USB/Bluetooth | OK | OK |
| Tracer Jula GTX 545 | - | Not supported | Not supported |

> **Note:** The Tracer Jula GTX 545 is not supported by Linux (discovered as HID device only).
